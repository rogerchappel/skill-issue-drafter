# Security

`skill-issue-drafter` is a local-first CLI. It reads finding JSON supplied by the operator and writes Markdown to stdout or an explicit output path.

## Reporting

Please report security issues through GitHub private vulnerability reporting when available, or open a minimal issue that avoids sensitive details.

## Boundaries

- Do not include private findings, credentials, or unreleased vulnerability details in public issues.
- The CLI should not require network access or secrets.
- Generated issue drafts should be reviewed before any external issue is created.
